# Public interface previews

These images show Folio's Compose UI with fictional demo titles, generated cover artwork,
and sample reading activity. They are interface previews, not a capture of a personal library.

- `home-light.png` and `library-light.png`: demo fixtures used in the reading-room and
  library-presence visual review. The current fixture setup is in
  `shared/src/desktopTest/kotlin/com/folio/reader/ReadingRoomPreviewTest.kt`.
- `reader-tools.png`: a composite of demo reader and manga tool previews. Reader fixtures
  are in `ReaderExperienceTest.kt`; manga previews use schematic panels rather than
  third-party manga artwork.

App chrome and available controls can differ by platform, version, theme, and window size.
These project-authored assets are distributed under the repository's Apache 2.0 license.
